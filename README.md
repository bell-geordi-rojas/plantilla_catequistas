# Plantilla de portadas para catequistas

Página web de un solo archivo (`index.html`) que genera una portada por persona a partir de una lista de nombres y las descarga juntas en un solo PDF.

## Cómo usarla

1. Escribe cada nombre en una línea.
2. Revisa la vista previa. Si un nombre se corta mal, escribe una barra `|` donde quieras el salto de línea.
3. Si lo necesitas, cambia el cargo, el tipo de letra o el color.
4. Pulsa **Descargar PDF**.

No necesita instalación: abre `index.html` en el navegador. Las fuentes de Google y la librería jsPDF se cargan desde internet.
